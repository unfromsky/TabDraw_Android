# 🎨 TabDraw Android 平板繪圖板客戶端

專為 Android 平板（特別是紅米 Pad / 小米 HyperOS）設計的滿血繪圖板專屬 App。

### 🌟 核心特色

- ⚡ **強制 120Hz 滿血刷新**：主動命令系統解除 60Hz 鎖頻限制，筆跡滑順，畫圓不變多邊形。
- ✍️ **手寫筆空中懸浮 (Airborne Hover)**：完整支援主動式手寫筆懸浮指針與壓感，徹底擺脫 Chrome 瀏覽器的 300ms 觸控掐斷限制。
- 🔄 **休眠喚醒自動重連**：即使平板螢幕熄滅休眠，喚醒後自動重連，手寫筆懸浮永不失效。
- 🌐 **自由設定電腦 IP**：支援輸入與記憶區域網路內任意電腦 IP（預設支援 `192.168.0.13:3000`）。
- 📺 **全螢幕沉浸式繪圖**：隱藏狀態列與導航條，支援螢幕常亮，繪圖不被中斷。
